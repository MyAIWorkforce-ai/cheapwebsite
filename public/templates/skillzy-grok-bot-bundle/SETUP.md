# Set up this Grok Bot — 5 minutes

Quick install guide for the bot you just bought on Skillzy.

## 1. Open Grok Studio

Sign in to Grok → click **Studio** → **New Bot**. Give it any name
you like (you can rename later).

## 2. Paste the system prompt

Open `system-prompt.md` from this bundle. Copy everything inside it.
Paste the whole thing into the Bot's **Instructions** field in Grok
Studio.

## 3. Upload the knowledge files

In Grok Studio, scroll to the **Knowledge** section → **Upload files**.
Upload every file in the `knowledge/` folder from this bundle. Grok
will chunk and index them automatically — no further config needed.

> Skip this step if the `knowledge/` folder is empty — some bots
> don't need reference material.

## 4. Enable the tools

Open `tool-permissions.md`. Toggle on the tools it lists in your Bot's
**Tools** panel in Grok Studio. If the file is empty or says the bot
doesn't need tools, skip this step.

## 5. Test it works

Open `test-prompts.md`. Try two or three of the example prompts in a
fresh chat with your new bot. If the outputs look right, you're done
— the bot is yours in your account, forever.

## Something not right?

Reply to your Skillzy order email — the creator sees it and can help.
Bundles also come with whatever support and update terms the creator
set out in `LICENCE.md`.
