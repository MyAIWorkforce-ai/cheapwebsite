# Skillzy Grok Bot Bundle Template

Starter kit for packaging a Grok Bot you want to sell on
[Skillzy.ai](https://skillzy.ai).

## What's in here

```
skillzy-grok-bot-bundle/
├── README.md               ← this file (delete before shipping)
├── SETUP.md                ← the handover doc buyers follow
├── system-prompt.md        ← your bot's Grok Studio instructions
├── knowledge/              ← reference files the bot uses
│   └── README.md           ← drop your PDFs/docs here (then delete)
├── test-prompts.md         ← prompts buyers try to confirm it works
├── tool-permissions.md     ← Grok tools the bot needs
└── LICENCE.md              ← terms for the buyer
```

## How to use this template

1. **Download + unzip** this folder.
2. **Fill in each file** — replace every `[bracketed placeholder]`
   with your bot's real content.
3. **Drop your knowledge files** into the `knowledge/` folder
   (PDFs, Markdown, docs) if your bot uses any.
4. **Delete this README and the `knowledge/README.md`** — buyers
   don't need to read notes meant for you.
5. **Zip the folder back up** and upload to Skillzy via `/sell/new`.
6. **Set a price** (recommended range: $29 – $149 depending on depth)
   and publish.

## Why this structure?

Grok doesn't have a single-click "export my bot" feature yet. This
bundle structure recreates the full configuration as portable files
so a buyer can rebuild your bot inside their own Grok account in
about 5 minutes.

Skillzy's post-purchase flow hands this zip straight to the buyer's
dashboard, re-downloadable forever. Once you've sold it, the buyer
owns their copy — you don't need to touch their Grok account.
