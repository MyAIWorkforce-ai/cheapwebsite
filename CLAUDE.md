# Skillzy — project & brand context

Shared memory for any Claude Code session (dev **or** marketing). The repo is
the source of truth — read this first and you can work in an isolated window
without losing the business/brand.

## What Skillzy is

A marketplace for AI **agent skills, guides, and full agent setups**. Creators
package something they built; buyers drop the files into any agent and it levels
up instantly. Creators keep **80%** of every sale; Stripe pays them direct
(Skillzy never holds funds); a listing resells forever.

- Buyer promise: *"Drop it in. Your agent just got smarter."*
- Creator promise: *"List once. Earn forever."*
- Manifesto line: *"You build. We sell. They use."* — "the creators' revolution".
- Three product types: `Skill`, `Guide`, `Agent Setup`.
- Works with: Claude · ChatGPT · Gemini · Grok · Ollama · Mistral · n8n · Make · Zapier.

## Brand voice

Short sentences. Confident, a little swagger. Never corporate. Numbers that
matter: **80%** creator / **20%** platform / **$0** held / **∞** resales.

## Visual system

- Colours: cream `#E8ECF0`, navy/ink `#0F1729`, gold `#C19E50`
  (soft `#DDB976`, dark `#9C7E3D`), muted `#5F6B7E`, hairline `#CCD2DD`.
  Full set in `tailwind.config.ts` under `theme.extend.colors.brand`.
- Type: **Fraunces** (display/serif, gold italic for emphasis) + **Inter** (UI,
  uppercase tracked labels). Brand tells: the hand-drawn **squiggle** underline
  and the rotated **sticker** chip.

## Stack & layout

Next.js 14 (App Router) · TypeScript · Tailwind · Supabase (auth/db) · Stripe
(Connect payouts) · Resend (email). Pages in `app/`, shared UI in `components/`,
domain logic in `lib/` (catalog, auth, stripe, env, email), DB in `db/`.
OG/social images use `next/og` (Satori) — see `app/opengraph-image.tsx`.

## Marketing / content

Lives in `marketing/`. `skillzy-content-playbook.md` is the explainer doc
(carousels, captions, hashtags, reel scripts, calendar). Instagram images
(1080×1350, on-brand) are generated by `scripts/gen-marketing-images.tsx` —
copy is data at the bottom of that file. Regenerate:

```
npx tsx scripts/gen-marketing-images.tsx
```

`em: true` = gold italic · `squiggle: true` = underline · `tone: 'navy'` = dark.
The font cache (`scripts/.fontcache/`) is gitignored and re-downloads on demand.
