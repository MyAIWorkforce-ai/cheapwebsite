# Skillzy — Instagram account setup

Everything you need to set up @skillzy on Instagram. Bios are
brutal — 150 chars total — so each version below is pre-counted.
Skillzy voice: punchy, no exclamation marks, no emoji-spam, ink
+ gold restraint.

## The link

Instagram only allows **one** clickable link in the bio. Three ways
to use it:

### 1. Direct (simplest)
`https://skillzy.ai` — sends everyone to the homepage.

**When this works:** the homepage already routes people clearly to
either Marketplace or Sell, so you don't need a separate link page
unless a campaign needs it.

### 2. /links route (custom Skillzy link-in-bio)

Build a `/links` page on the site that mirrors what Linktree does, but
on your own domain — better for SEO, better tracking, more on-brand.

Want me to build this? Say the word and I'll ship a `/links` page
with the layout below in ~5 minutes of code. Layout:

```
Skillzy
Your agent just got smarter

→ Browse the marketplace        [/marketplace]
→ Sell your skill in 30 seconds [/sell/new]
→ Read the manifesto            [/about]
→ Latest dispatches             [/dispatch]
→ Listen to a creator           [/dispatch/<latest-post>]
```

### 3. Per-campaign tracked links

Use `skillzy.ai/?ref=ig` (or any `?ref=<channel>` suffix) so Vercel/
Sentry/Plausible can attribute traffic by source.

## Highlights — the four covers you'll want first

Instagram lets you pin "Highlights" — circular thumbnails on your
profile that group Stories. Set these up day-one:

1. **🟢 New** — what Skillzy is in 5 frames. Use the manifesto card +
   the four key product types.
2. **🟢 Sell** — walkthrough of /sell/new. Drop a file → AI drafts →
   publish. Beat 5 from the website explainer.
3. **🟢 Buy** — show the buyer side. Browse marketplace → drop a
   skill in → agent runs sharper.
4. **🟢 Creators** — testimonials, "built this for my own work"
   moments, who's published already.

Each Highlight cover should be a cream square (`#F2F4F8`) with a
single short word in gold Fraunces ("New" / "Sell" / "Buy" /
"Creators"). Keep them visually identical so the profile reads as
one quiet typographic set.

## Pinned grid — the first 9 posts buyers see

When someone lands on your profile they see your 9 most recent
posts. Pick the strongest 9 from the launch pack and order them so
the **top row** reads as a brand reveal, the **middle row** says
"this is what you can sell", and the **bottom row** has a real
example or testimonial.

Recommended order (newest at top-left, oldest at bottom-right —
remember Instagram fills left-to-right, top-to-bottom):

```
ROW 1  | Brand reveal      | Manifesto card    | Keep 80% card
ROW 2  | 3 product types   | Five-step grid    | Built-by-creators
ROW 3  | Niche callout     | "Good email" mock | Quote from creator
```

That trio of rows tells the whole story before anyone watches a reel.

## Followers strategy — first 100

Skillzy's first 100 followers should be creators in the niches you
already cover (Real Estate, Tradies, Bookkeepers, Coaches). Find them by:

1. Search hashtags: `#AISkills`, `#ClaudeSkills`, `#PromptEngineering`,
   `#AIWorkflow`, `#n8n`, `#CreatorEconomy`
2. Follow people posting about agent setups, SKILL.md files, prompt
   templates — they're your creators
3. DM the first 20: short, real, no script — "saw your post on X, we
   just launched a marketplace for that. happy to be your first listing
   — link if you want it."

Don't chase numbers. Chase the right 100.
