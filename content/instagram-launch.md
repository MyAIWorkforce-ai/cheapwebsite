# Skillzy — Instagram launch content pack

> **10 Reels + 10 static posts.** Each one is a self-contained brief
> you can paste into your video-generating Claude / Higgsfield session
> or into Canva for the static ones. Copy is already in the Skillzy
> voice (short sentences, verbs first, no hype, no exclamation marks,
> no emoji) so it's ready to ship.

**Brand palette to reference in every visual:** gold `#C19E50`,
ink/navy `#0F1729`, cream `#F2F4F8`. Display font: Fraunces (serif).
Body font: clean sans (Inter / SF Pro).

## How to use this pack

For the **10 Reels**:
1. Open your Higgsfield-connected Claude
2. Paste one reel brief at a time (Hook + Beats + On-screen captions)
3. Tell Claude: "Make this as a 30-second vertical video, Skillzy brand palette gold/ink/cream, serif display type. Voiceover optional."
4. Once rendered, post with the matching caption + hashtags below it.

For the **10 Static posts**:
1. Open Canva (or any design tool)
2. Set canvas to 1080×1080
3. Use the Visual brief as the layout instruction
4. Apply the colour palette: gold `#C19E50`, ink `#0F1729`, cream `#F2F4F8`
5. Display font: Fraunces. Body: any clean sans.
6. Pair with the caption + hashtags listed.

## Posting cadence suggestion

Two posts per day for two weeks gets you launched:
- **Morning:** static post (quick scroll-stopper)
- **Evening:** reel (engagement driver)

Save the manifesto card (Post 1) and the brand reveal (Post 10) for **day 1** and **day 14** as bookends.

Track which posts drive `/sell/new` page visits via your GSC + Vercel analytics (once Sentry is on) to see what's converting creators.
