## Description (What it does.)

A full website-build desk for your agent. Drop this bundle in, tell
it what you're building and who it's for, and it walks you from
blank page to live URL: discovery → information architecture →
scaffold → content writing → deploy → custom domain → SEO →
analytics → forms → launch QA → standing-by maintenance.

Handles the full loop: brief arrives ("I'm a coach charging $250 a
session, need a booking site") → six questions of discovery →
sitemap planning with conversion paths → Next.js + Tailwind project
scaffolded → actual page copy written (not lorem ipsum, not generic
filler — real hero, real services, real about, real FAQ) → deployed
to Vercel → custom domain wired with DNS hand-holding for any
registrar → on-page SEO (meta + JSON-LD + Core Web Vitals) → AI
search ready (`llms.txt`, structured patterns Claude / ChatGPT /
Perplexity actually read) → analytics with conversion events →
consent banner picked for the buyer's region → forms with anti-spam
→ launch checklist (a11y, perf, security, legal) → live → then
stays on standby for every later change.

Universal across Australia, New Zealand, the UK, the US, and Canada
— the regional reference maps every privacy law (Privacy Act 1988
+ APPs / Privacy Act 2020 / UK GDPR + DPA 2018 / CCPA + state
patchwork / PIPEDA + Quebec Law 25), every TLD body (auDA / DNCL /
Nominet / NeuStar / CIRA), every tax label (GST 10% / GST 15% /
VAT 20% / state sales tax / GST + PST/HST), every consent
requirement (none if Plausible / Cookiebot / Iubenda / Termly /
CookieYes / OneTrust), every accessibility regime (DDA + AS / UK
Accessibility Regs / ADA / Quebec Web Accessibility Standard), every
language quirk (bilingual EN+FR required for Quebec under Law 25).

Performance, accessibility, and privacy baked in from day one — not
afterthoughts. Core Web Vitals targets met (LCP <2.5s, INP <200ms,
CLS <0.1, Lighthouse 90+). WCAG 2.1 AA compliance — semantic HTML,
keyboard navigable, alt text, contrast checked, screen reader
friendly. Region-correct cookie consent before any tracker fires.

Comes with a pointer to the **Stripe Setup, end to end.** bundle for
the payments side — no duplicated content, both bundles plug into
each other cleanly. The site-builder bundle handles the website
craft; the Stripe Setup bundle handles the payments craft.

Maintains a running `learnings.md` so the agent gets sharper every
project — tracks which page-types convert for which audiences, which
CMS / stack choices ended up actually shipped, which DNS gotchas
keep showing up (Cloudflare proxied vs DNS-only, ANAME records at
apex, CAA records blocking Let's Encrypt), which form providers
spam-filter best, which analytics setups buyers actually look at.

Built for solo founders, freelance designers, web shops, marketers,
and operators who want a small-business site shipped this week, not
this quarter.

## What's inside.

    legal requirements

    (audience, single primary CTA, tone, scope, region, payments
    yes/no)

    paths, page hierarchy decisions (one-pager vs marketing vs

    Astro / WordPress / Webflow alternates), project bootstrapped,
    builds locally, ready for content
05. Content writing skill — page-by-page playbook for the hero,
    social proof, features, services, about, pricing, FAQ, CTA —

06. Deploy-to-Vercel skill — GitHub repo, Vercel import, preview

    Cloudflare, Porkbun, Squarespace Domains, GoDaddy, Crazy Domains

    HSTS, CDN, redirects
08. SEO on-page skill — meta + Open Graph + Twitter cards + JSON-LD

    sitemap, robots, canonicals, `llms.txt`, Core Web Vitals tuning

14. Templates — sitemap, homepage content, about, services, pricing,

15. Regional reference — AU / NZ / UK / US / CA web hosting, privacy
