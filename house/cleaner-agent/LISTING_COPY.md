## Description (What it does.)

A full cleaning business desk for your agent. Drop this bundle
in, tell it your services + rates + region + compliance docs
(police check, WWCC / DBS / NDIS clearance, public liability),
and it runs the whole desk: intake, quoting, crew scheduling,
checklist sign-off + photo evidence packs, invoicing (including
direct debit for recurring), follow-ups, supplier orders, urgent
jobs, and weekly reports.

Handles the full loop: text arrives ("need a bond clean by
Friday, 3-bed unit") → qualify → quote within 15 minutes → book
the crew → on-the-way SMS → on-site checklist → time-stamped
photo evidence pack → invoice with payment link → next-day
check-in → 3-day review request → recurring-conversion offer →
end-of-week report + learnings update. Then repeats. Forever.

Universal across Australia, New Zealand, the UK, the US, and
Canada — the regional reference inside the bundle maps every
term (bond clean vs end-of-tenancy vs move-out, COSHH vs SDS,
NDIS clearance vs DBS vs vulnerable sector check, GST vs VAT)
so you don't need to teach the agent which country you're in.

Cleaning-specific built in: knows the difference between a bond
clean (3-bed, 6-8 hrs, photo evidence, 72-hour guarantee, REIQ /
RTA checklist), a recurring fortnightly (4 hrs, 2 cleaners,
auto-renew contract, GoCardless or PayTo direct debit), a
commercial nightly (offices, alarm codes, after-hours, key
holder), and a STR turnover (2-hour window, linens, restocks,
photo pack for the host). Knows that "the recurring" is the
goal of every one-off. Knows that NDIS work requires Worker
Screening Check + Orientation Module + Code of Conduct. Knows
that bond cleans without photo evidence are bond cleans you'll
do twice.

Maintains a running `learnings.md` so the agent gets sharper
every week — tracks which job types win on margin (recurring
residential vs one-off bonds vs STR turnovers), which suburbs
let you cluster best, which crew members earn 5-star reviews,
which chems give the best yield per litre, and which bond
agents in your area are the pickiest. Update the rates once;
every later quote respects them.

Built for solo cleaners, residential firms, commercial crews,
bond specialists, STR turnover operators, and cleaning business
owners who want to spend more time billing and less time
chasing texts.
