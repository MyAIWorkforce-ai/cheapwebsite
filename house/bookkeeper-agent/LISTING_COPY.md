## Description (What it does.)

A full bookkeeping practice's desk for your agent. Drop this bundle
in, tell it your jurisdictions, software stack (Xero / QBO / MYOB /
Sage / Karbon / Ignition), service tiers, BAS-agent number or HMRC
AML registration, and it runs the whole desk: prospect intake,
engagement letters, monthly fixed-fee quoting, software stack
onboarding, weekly workflow, monthly close rhythm, BAS / VAT /
sales-tax preparation, recurring direct debit billing, source-doc
chasing, deadline-rescue triage, post-lodgement reviews, annual
review meetings, and weekly WIP + receivables reports.

Handles the full loop: prospect email arrives ("14 months behind on
BAS, can you help") → qualify the work → AML/CTF source-of-funds
check → engagement letter via Ignition / Karbon → tiered monthly
fixed-fee quote → Xero subscription + Hubdoc + bank feed setup →
weekly workflow (source-doc sweep Monday, coding + reco Tue-Wed,
partner review Thursday) → monthly close (week 1-2) → quarterly BAS
prep + lodgement → invoice via direct debit → post-BAS review nudge
+ annual review meeting + extension to advisory. Then repeats.
Forever.

Universal across Australia, New Zealand, the UK, the US, and
Canada — the regional reference inside the bundle maps every
framework (BAS quarterly vs VAT MTD vs sales tax by state vs
GST/HST/PST, TPB BAS-agent vs HMRC MTD agent enrolment vs IRS PTIN
vs CRA RAC, STP Phase 2 vs RTI vs Form 941 vs T4 source deductions,
ICB Australia vs AAT/ICB UK vs NACPB vs CPB Canada) so you don't
need to teach the agent which country you're in.

Bookkeeping-specific built in: knows the difference between a
one-off (catch-up, EOY clean-up, BAS-only) and a recurring monthly
package (Compliance only / Basic / Full-service / CFO-lite). Knows
that lodgement for fee in AU requires TPB BAS Agent registration —
and won't lodge without it. Knows that UK firms must be AML
supervised (HMRC or professional body) before onboarding any
client. Knows that source-doc discipline is the difference between
a 30-min reconciliation and a 3-hour mess. Knows that Hubdoc /
Dext are the receipt-capture layer and A2X is the Shopify/Amazon
sync layer. Knows that the highest-margin moment of the year is
the EOY annual review meeting where you re-tier and extend the
engagement into advisory.

Builds the monthly fixed-fee model into every prospect quote — the
agent never quotes hourly for recurring work, because hourly is the
trap that kept the practice small. Three tiered options, scope and
exclusions explicit, recurring direct debit via GoCardless /
Stripe / Ignition. Target attach: 70%+ of new clients on a monthly
package by month 3.

Maintains a running `learnings.md` so the agent gets sharper every
week — tracks which client tiers actually deliver margin (A clients
on full package vs C clients on compliance-only), which industries
send source docs on time (trades, eComm, hospitality have very
different patterns), where you're losing recoverable hours (manual
data entry that Hubdoc would kill), which referral partners
(accountants, financial planners, business coaches) convert.
Update the rates once; every later quote respects them.

Built for solo bookkeepers, BAS agents, contract CFOs, and small
practices (1-15 staff) who are tired of drowning in source-doc
chase emails and Karbon tickets, and want to get back to the work
that actually pays — recurring monthly engagements, EOY annual
reviews, advisory conversations.
