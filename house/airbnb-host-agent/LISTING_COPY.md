## Description (What it does.)

A full short-term rental hosting desk for your agent. Drop this
bundle in, tell it your properties (one block per listing), your
channel mix, channel manager, dynamic pricing tool, cleaner network,
smart-lock + noise sensor setup, regulatory status (STR registration
+ lodging tax + insurance), and it runs the whole desk: triage every
inquiry within minutes (Superhost response-time discipline), quote
direct bookings with length-of-stay discount, dispatch turnovers
the moment a checkout confirms, run the pre-arrival comms sequence
(booking confirm → 7-day reminder → 24h check-in code → day-of "you
in OK?"), handle mid-stay support, request reviews at the right
moment, respond to every review, track channel payouts vs. direct
revenue, flag regulatory deadlines, and report weekly per-property
on occupancy + ADR + RevPAR + profitability.

Handles the full loop: inquiry arrives ("any chance for 5 nights
end of March?") → triage with party-risk filter → rate quote in
minutes → booking confirm → welcome pack → 7-day reminder + parking
+ arrival window → 24h check-in code + wifi + first-night essentials
→ day-of "you in OK?" 6pm → mid-stay day-2 check → checkout reminder
→ 1hr after checkout, cleaner dispatched + lock code rotated →
turnover all-clear → next guest ready → post-stay thank-you →
review request → review response. Then repeats. Forever.

Universal across Australia, New Zealand, the UK, the US, and Canada
— the regional reference inside the bundle maps every regulatory
regime: NSW STRA Code + 180-night Greater Sydney cap, VIC 7.5%
STRA levy (Jan 2025), Edinburgh STL mandatory licence, London 90-day
non-hosted rule, NYC Local Law 18, San Francisco 90-night limit, LA
Home-Sharing Ordinance, BC Bill 35 Short-Term Rental Accommodations
Act, Toronto principal-residence by-law, Vancouver primary-residence
business licence, Montreal CITQ. The agent refuses to confirm new
bookings if the property isn't registered where it's required —
hosting unlicensed is the operator's biggest legal risk and the
agent's hard refuse.

STR-specific built in: knows the difference between Airbnb's tone
(first-name, breezy), Booking.com's (transactional, skimmable),
VRBO's (family-warm), and direct-booking's (you've earned this
guest — warmest). Knows that "the listing", "the calendar", "the
turnover", "the cap" (night limit), "the host fee" (channel
commission), "Superhost", "Premier Host" (VRBO), "Genius" (Booking)
are real words. Knows PriceLabs vs Beyond vs Wheelhouse, Hospitable
vs OwnerRez vs Hostaway vs Guesty vs Lodgify vs iGMS vs Hostfully,
Igloohome vs RemoteLock vs August, NoiseAware vs Minut, Turno vs
Tidy vs Breezeway vs Properly.

Maintains a running `learnings.md` so the agent gets sharper every
week — tracks which properties earn highest RevPAR, which channels
have the worst guest mix per property, which weeks the dynamic
pricing under-quoted, what the average lead time is per property,
which cleaner consistently turns over on time, which house rules
get violated most, which review themes are emerging (good + bad).

Built for solo Airbnb hosts and small portfolio managers running
1-50 properties who want to spend less time on the phone with
guests at 11pm and more time scaling the business.
