# Getting Started With AI Agents
### The plain-English starter guide for non-technical operators

---

## 1. What an AI agent actually is

A chatbot answers questions. An **agent** does the work.

An AI agent is a general AI (like Claude) that has been given:
- **one specific job**,
- **clear instructions** for how to do it, and
- **access to the tools** it needs (your inbox, calendar, spreadsheet).

Picture it like this: a chatbot is a smart person you message. An agent
is a smart person you *hired*, trained for one task, and pointed at your
inbox. It runs the task the same way, every time, often unattended.

## 2. What a "skill" is

You don't re-explain the job every time. You hand the agent a **skill** —
a single file (a `SKILL.md`) that holds:
- the **intent** (what this does),
- the **inputs** (what it needs from you),
- the **steps** (how it does it),
- the **output** (what you get back).

Drop the file into the agent and it knows that job. Stack a few skills
and you have an agent that runs a whole desk.

Why a file, not a prompt? A file is versioned, shareable, reviewable,
and survives a model upgrade. That's the whole basis of a skills
marketplace.

## 3. What it can actually do for a small business

Real, boring, money-saving things:

- Answer the "do you have Saturday?" booking DMs and book them in
- Turn a job photo + a few notes into an itemised quote
- Chase overdue invoices in a tone that keeps the client
- Triage after-hours calls so you only wake for real emergencies
- Write the weekly client update from your task list, in your voice
- Sort the inbox and draft the replies you'd send anyway

## 4. How to get started — no code

1. **Pick ONE job** that eats your time every week. Start narrow. Not
   "automate my business" — "draft the quote from a photo".
2. **Pick a platform.** Claude is the easiest place to begin. n8n /
   Make / Zapier connect it to your other tools when you're ready.
3. **Get the skill.** Buy a proven one from a marketplace, or write
   your own using a starter guide.
4. **Drop it in** and run it on one real example from last week.
5. **Tune it once** — edit the voice/config block so it sounds like
   you. Then let it run and check its work for a few days.
6. **Add the next skill** only once the first one is trusted.

## 5. The one rule that keeps you out of trouble

> Don't try to automate everything. Automate the one task you'd pay a
> person to take off your plate, prove it works, then add the next.

Agents fail quietly when they're vague. Narrow + boring + reviewed
beats clever every time.

## 6. Mini-glossary

- **Agent** — an AI given a defined job + tools, runs it unattended.
- **Skill / SKILL.md** — one capability handed to an agent as a file.
- **Agent Setup** — a bundle of skills that runs a whole role.
- **Platform** — where the agent lives (Claude, OpenClaw, n8n…).
- **Config / voice block** — the bit you edit once so it sounds like you.

## 7. Your next move

- Want to be running today? Get a ready-made skill or full setup and
  drop it in.
- Want to build your own? Start with a "first agent" walkthrough and
  the SKILL.md format.

Either way: pick one task, ship it, expand. That's the whole game.
